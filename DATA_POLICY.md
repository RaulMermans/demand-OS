# DemandOS Data Policy

## MVP: Synthetic/Mock Data Only

The DemandOS MVP uses fully synthetic, machine-generated data.
No real customer data, order data, personal data, or financial data is processed.

All data in `data/` directories is:
- Generated by `scripts/seed_demo_data.py` using `MockCommerceConnector`
- Structurally realistic but entirely fictional
- Safe to share, commit (if small), and use in demos

## Allowed Raw Data

DemandOS is designed to ingest raw operational records:
- Product catalogs (names, SKUs, categories, prices)
- Store/channel definitions
- Order line items (product, quantity, price, timestamp, status)
- Inventory snapshots (product, location, quantity on hand)
- Promotion calendars
- Supplier definitions
- Purchase orders

## Prohibited Data

The following must never be ingested, stored, or logged:
- Personal data: names, email addresses, phone numbers, home addresses
- Payment data: card numbers, bank accounts, payment tokens
- Health data or any special category data (GDPR Article 9)
- Authentication credentials: passwords, API keys, access tokens

## If Real Data Is Used (Sprint 7+)

When real Shopify/WooCommerce/ERP connectors are activated:
1. Document the data source, legal basis for processing, and data owner.
2. Verify that PII is excluded from raw records or anonymized before storage.
3. Apply a data retention policy (e.g., raw records purged after 13 months).
4. Document a deletion procedure for when a customer account is terminated.
5. Ensure `raw_payload` column does not store PII from real orders.
6. Never log field values from real orders — log IDs and counts only.
7. Credentials for real connectors are stored in the secrets manager only.

## Credentials Policy

- Never store API keys, OAuth tokens, or passwords in the database.
- Never log credential values.
- Never commit `.env` files containing real credentials.
- Use `.env.example` to document required variable names only.

## Data Location

| Data | Location | Permitted |
|------|----------|-----------|
| Synthetic mock data | `data/raw/`, `data/processed/` | ✅ |
| Sample CSV uploads | `data/sample_uploads/` | ✅ (synthetic only) |
| Real customer orders | Anywhere in this repo | ❌ |
| Trained model artifacts | `models/` | ✅ |
| Database file (SQLite dev) | `apps/api/demandos_dev.db` | ✅ (gitignored) |
